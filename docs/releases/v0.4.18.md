# VuNMix v0.4.18

Desktop memory/resource fixes after v0.4.17:

- Close media artwork streams after success, error and cancellation.
- Close microphone streams when PortAudio start fails before retry.
- Cache current-track artwork and limit compressed size/decoded pixel count.
- Serialize media refresh and bound asynchronous media queries.
- Read selected endpoint volume/meter directly instead of enumerating every endpoint.
- Fix default-speaker ID access and microphone change detection.
- Log process RSS/private memory, threads and handles every five minutes while telemetry runs; include a snapshot in diagnostics.

Validation before release build: 68 focused local tests passed (Windows imports stubbed). Cleanup regression tests fail on v0.4.17 and pass on the fix. Windows unit tests and packaging are required by the release workflow. A multi-hour native Windows RAM plateau has not been verified on the affected machine.
